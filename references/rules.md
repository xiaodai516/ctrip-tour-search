# 判定规则与排除码

> 适用数据集：`data/products.json`（2026-11-22 快照，来源为携程列表页 SSR 内嵌 JSON）

## R1 携程自营判定（分三层，不许混说）

| `brand_status` | 含义 | 凭据 |
|---|---|---|
| `verified_self_operated` | 自营已核验 | ①详情页「供应商：携程自营（可查看经营许可证/营业执照）」；或②产品标题自带 `携程自营` / `携程国旅` / `自营` 标识 |
| `unverified_no_brand_field` | 无法核验 | 携程列表页 JSON 不含供应商字段，标题也无自营标识 |
| 被排除 | 非自营/查无 | 详情页供应商为具名第三方（如「纵览山河旅行」「寰宇纵横」） |

关键事实（实测，2026-11-22）：

- 列表页 `"products":[...]` 每条只有 `id / productTypeName / name / mainName / subName / departures / locations / level / minDays / maxDays / extras`，**没有供应商、没有品牌、没有 priceInfo**。
- 列表页 SSR **不响应任何筛选参数**：`filter=cb`、`filter=zscb1`、`?cb=`、`?zscb=`、`?brand=`、`?filterJson=` 全部实测与不加参数结果完全一致（同页 30 条编号相同）。品牌筛选只在前端异步完成。
- 详情页 `/travel/detail/p{id}`、`tourbst.ctrip.com`、`m.ctrip.com/webapp/xtour/detail` 均返回同尺寸 JS 空壳（122749 字节），无登录态拿不到供应商。

因此自营只能按「有凭据才标 ✓」处理，**绝不因为某个产品看起来像自营就标自营**。

## R2 产品类型判定（拼小团 vs 跟团游）

**只看主标题段**（第一个 `·` 之前），副标题常出现「含自由行」「私家团」「半自助」等干扰词，不参与判定。

| 主标题含 | 归类 |
|---|---|
| `拼小团` | `拼小团` |
| `跟团游` | `跟团游` |
| `私家团` / `自由行` / `一日游` / `半日游` / `研学` / `独立营` / `邮轮` / `游轮` | 排除，写对应排除码 |

交叉情况：

- 主标题写「跟团游」但副标题写「9人小团」「纯玩小团」→ **仍记 `跟团游`**。类型以官方主标题为准，不按体量重分类。
- 主标题写「拼小团」但注明「N人可升级独立成团」→ 仍是 `拼小团`，升级属可选项。

## R3 含机票判定（核心口径）

```
出发地参团 = 含机票
当地参团（= 目的地参团）= 不含机票
```

本数据集直接用**列表归属**判定，比正文推断更可靠：

| 出现的列表 | `departure_mode` | `includes_flight` |
|---|---|---|
| 仅 `list/whole/...` | 出发地参团 | `true` |
| 仅 `list/around/...` | 当地参团 | `false` |
| 两处都出现 | `null`（输出「两处均在售」） | `null`（输出「不唯一」） |

判定依据写在 `flight_basis` 字段。两处都在售时**不强行择一**，因为该编号确实同时提供含机票与不含机票的套餐。

## R4 钻级标准

取列表页 `basicInfo.level`（字符串 `"1"`–`"5"`），即**携程产品钻级**，`diamond_basis = product_level`。

- 取值 1–5 → `diamond_level = N`，输出 `N钻`
- 字段缺失/非数字 → `null`，输出 `未披露`，不猜
- 不要把钻级说成酒店星级；本数据集不采集住宿钻级

## R5 天数

取 `basicInfo.minDays` 的整数值（与标题「X日Y晚」的 X 一致），`nights` 取 `extras.NIGHTS`。

- `6日4晚` 合法（夜宿飞机），不要因晚数异常改天数
- `17日16晚`、`15日0晚` 这类长线/无晚数都按原值保留

## R6 缺失字段处理

| 缺失字段 | 处理 |
|---|---|
| `product_id` | 排除（无编号无法回溯，无法核对） |
| `destination_group` | 排除，目的地无法归入六国 |
| `days` | 排除，`MISSING_DAYS` |
| `diamond_level` | **保留**，标 `未披露` |
| `price_from` | **保留**，本轮统一 `null`（列表页不返回价格） |
| `brand_status=unverified` | **保留**，但默认不进结果，只在「未核验候选」块展示 |

原则：**信息缺失不等于不合格**，但缺失必须可见；只有「无编号 / 无目的地 / 无天数」才排除。

## 排除码总表

| 码 | 中文 | 触发 |
|---|---|---|
| `PRIVATE_TOUR` | 私家团（不在范围） | 主标题含「私家团」 |
| `FREE_TRAVEL` | 自由行（不在范围） | 主标题含「自由行」 |
| `DAY_TOUR` | 一日游/半日游（不在范围） | 主标题含「一日游/半日游」 |
| `NOT_GROUP_TOUR` | 非跟团类（研学/邮轮等） | 主标题含研学/独立营/邮轮/游轮，或类型非跟团游/拼小团 |
| `TYPE_UNKNOWN` | 类型无法判定 | 主标题既非拼小团也非跟团游 |
| `MISSING_DAYS` | 缺少行程天数 | 无 minDays |

`validate` 强制：合格记录不得带排除码；排除记录必须带排除码；`brand_status` 与 `is_self_operated` 必须一致。
